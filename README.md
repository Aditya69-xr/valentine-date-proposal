# 💖 Valentine's Day Date Proposal Web App

A breathtaking, modern, and romantic Valentine's Day date proposal web experience built with **React**, **Vite**, and **Tailwind-inspired glassmorphism**.

---

## ✨ Features

- **Royal Decorated Emblem:** 3D glowing heart with Cupid wings, royal tiara, and animated script ribbon.
- **Full-Screen "No" Button Evasion:** The "No" button playfully teleports across the entire browser viewport when hovered or touched!
- **Progressive "Yes" Button:** Every time "No" is chased, the "Yes" button expands with celebratory confetti and pulsing glow.
- **Interactive Date & Time Scheduling:**
  - Date Selection (bounded to 2026, default Feb 14).
  - Time Availability presets (7:00 PM Candlelight Dinner, 5:00 PM Sunset Walk, Custom).
  - Food Selection (Pizza, Coffee Date, Burger, Noodles, Ramen, Date).
  - Personal message & sweet suggestions.
- **WhatsApp Notification & Direct Messaging:**
  - Sliding realistic WhatsApp push alert banner.
  - VIP Valentine Date Pass Ticket (`#VAL-2026-LOVE`).
  - 1-click WhatsApp redirect with pre-filled romantic summary message.
- **Real-time Wikipedia Lore:** Fetches live historical data for Valentine's Day, St. Valentine, and Cupid via Wikipedia REST API.
- **Ambient Romantic Melody:** Browser-native Web Audio API synthesizer for acoustic love chords.

## 🚀 Running in VS Code (Quick Start)

### 1. Open in VS Code
Open this folder `d:\VALENTINE` in Visual Studio Code:
```bash
code .
```

### 2. Install Dependencies
Open terminal in VS Code (`Ctrl + ~`) and run:
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open **`http://localhost:5173/`** in your browser.
